# Py-calc
## About me
Py-calc or Pycalc is like [calc](http://www.isthe.com/chongo/tech/comp/calc/), but written in Python instead of C.
## Install me
Just go to Releases, select one release, and download it. See INSTALL.md for more instructions.
## Software used
I used [PyCharm](https://www.jetbrains.com/pycharm/) for the code. Its integrated VCS lets me edit code remotely from PyCharm.
